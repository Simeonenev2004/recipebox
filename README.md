# RecipeBox

RecipeBox is a single page React application for sharing and discovering recipes.

## Installation & Running

1. Copy `.env.example` to `.env` and fill in your Firebase keys.
2. Run:

```bash
npm install
npm run dev
npm run build
```

https://recipebox-ee99f.web.app
